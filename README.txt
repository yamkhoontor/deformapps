COMPANION APPS - OFFLINE VERSION
================================

This folder contains the ten interactive apps that accompany the book.
They run in any modern web browser (Chrome, Edge, Firefox, Safari) on
Windows or Mac, with no installation and no internet connection.

HOW TO USE
1. Unzip (extract) the downloaded file to a folder on your computer.
   On Windows: right-click the zip file and choose "Extract All".
   On a Mac: double-click the zip file.
2. Open the folder and double-click START_HERE.html.
3. Choose an app. Each opens with the book's data already entered.

Keep all the files in the same folder: START_HERE.html links to the others.

  part1_solver.html           Part I    Foundations
  part2_solver.html           Part II   Least squares adjustment

  part6_solver.html           Part VI   Kinematic and dynamic analysis

  part8_solver.html           Part VIII Sensors, practice and case studies
  appendixE_solver.html       Appendix E Generalized inverses

NOTES
- All calculations run on your own computer; no data are sent anywhere.
- Without an internet connection the apps use your computer's standard
  fonts; everything else works exactly the same.
- On tablets and phones, use the online versions linked from the book.
