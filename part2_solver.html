Part II Solver

Calculators for the Part II exercises of Deformation Monitoring and Analysis: least squares, sequential updating and variance components. Each opens with the exercise values; change any number to see the working update.

Levelling weights

Exercise 1: lines of 0.5, 1.2 and 2.0 km with σkm = 1.5 mm/√km. Find each σ and its weight, taking 1 km as unit weight.

Levelling network adjustment

Exercise 2: re-adjust Example 4.3 with equal weights. Exercise 4: does the global test pass with σ0 = 1 mm/√km, and what is the smallest σ0 that passes?

Redundancy and condition equations

Exercise 3: 12 observations and 7 unknown coordinates, no datum defect. How many independent condition equations are needed?

Sequential update and innovation test

Exercise 5: add a second A → C line (+3.004 m, 2 km, weight 0.5) to the Example 4.3 solution. Exercise 7: what innovation would just fail the test?

Linearization coefficients

Exercise 6: pillar S(20, 30), approximate target (80, 110). Write down the distance coefficients.

Iterative variance component estimation

Exercise 8 and Example 6.3: two instruments measure the same baseline. Watch the redundancy shares change as the weights are re-estimated.

Variance factors from group residuals

Exercise 9: directions give vᵀPv = 24.0 with r₁ = 12.0; distances give 3.0 with r₂ = 6.0. Compute the first-iteration factors.

All computations run in your browser. Critical values are computed from the χ² distribution, not looked up from tables.
