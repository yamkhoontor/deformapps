Appendix E Solver

Calculators for the Appendix E exercises of Deformation Monitoring and Analysis: generalized inverses, null-space matrices, configuration defects and rank decisions. Each opens with the exercise values; change any number to see the working update.

Generalized inverses of a levelling network

Exercise 1: recover N⁺ from (N + EEᵀ)⁻¹. Exercise 2: fixing any one point of the Part III network gives trace 1.50. Choose the datum and compare.

Null-space matrix with orientation unknowns

Exercise 3: a 2D network of 6 points and 4 set-ups observed with directions and distances. Build E and check that a rotation changes no observation.

Configuration defect checker

Exercise 4: a point tied to the network by a single distance. Count the zero eigenvalues and compare with the datum defect (3 for a distance network).

Rank tolerance pitfall

Section E.6, Pitfall 1: displacements from one datum with a cofactor matrix from another, plus floating-point noise. Watch the congruency statistic as the tolerance changes.

All computations run in your browser. Eigenvalues are computed with the Jacobi method for symmetric matrices.
